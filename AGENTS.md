# PocketPet Project Rules

## Product

PocketPet is a native Apple Watch virtual pet app.

## Core Principles

- Use Swift and SwiftUI.
- Design Apple Watch first.
- Use Apple frameworks only unless explicitly requested.
- Do not add a backend for the MVP.
- Do not add third-party dependencies.
- Keep implementation simple.
- Avoid premature abstractions.
- Avoid unrelated refactors.
- Pet artwork will be added later.
- Keep placeholder visuals easy to replace with final pet assets.
- Ensure the UI works well on small Apple Watch displays.
- Prefer reusable components only when they reduce duplication.
- Persist local state using simple native storage.
- Do not implement features that were not explicitly requested.
- Inspect only files relevant to the current task.
- Always build or check for compiler errors after changes.
- Keep the final response concise: changed files, result, and any remaining issue.
